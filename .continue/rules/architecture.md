# Architecture Rules

- Use Next.js App Router only
- Use route groups: (site), (auth), (dashboard)
- Do not redesign UI unless explicitly requested
- Prefer Server Components by default
- Use Client Components only when interactivity is required
- Avoid duplicated layouts/components
- Preserve current premium visual design
- Keep strict TypeScript compatibility
- Avoid legacy Pages Router patterns
- Prefer modular reusable components
- Do not introduce unnecessary abstractions
